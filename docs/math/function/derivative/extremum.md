# 极值与最值

**前置知识**：[导数与单调性](monotonicity.md)

!!! note "考纲要求"
    理解函数极值的概念；掌握极值的必要条件（$f'(x_0) = 0$）和充分条件（一阶导数变号）；掌握闭区间上函数最值的求法。

## 定义

**极值**：设函数 $f(x)$ 在 $x_0$ 处有定义，且对 $x_0$ 附近的任意 $x$ 有 $f(x) \leqslant f(x_0)$（极大值）或 $f(x) \geqslant f(x_0)$（极小值），则 $f(x_0)$ 称为极值。

**极值点**：使函数取得极值的 $x_0$ 称为极值点。

## 极值的求法

### 必要条件

若 $f(x)$ 在 $x_0$ 处可导且取极值，则 $f'(x_0) = 0$。称 $x_0$ 为**驻点**。

### 充分条件（一阶导数变号法）

若 $f'(x_0) = 0$，且：
- $f'(x)$ 在 $x_0$ 左侧为正、右侧为负 → 极大值
- $f'(x)$ 在 $x_0$ 左侧为负、右侧为正 → 极小值
- $f'(x)$ 在 $x_0$ 两侧不变号 → 不是极值点

### 充分条件（二阶导数法）

若 $f'(x_0) = 0$ 且 $f''(x_0)$ 存在：
- $f''(x_0) < 0$ → $f(x_0)$ 为极大值
- $f''(x_0) > 0$ → $f(x_0)$ 为极小值

## 最值的求法

求 $f(x)$ 在 $[a,b]$ 上的最值：
1. 求出 $f(x)$ 在 $(a,b)$ 内的极值
2. 计算 $f(a)$、$f(b)$
3. 比较所有极值和端点值，最大者为最大值，最小者为最小值

## 例题

### 【例1】（基础题）

求 $f(x) = x^3 - 3x^2 + 1$ 的极值。

??? note "解析"
    $f'(x) = 3x^2 - 6x = 3x(x-2)$，驻点 $x=0,\;x=2$。
    
    $f'(x)$ 符号：$x < 0$ 时 $f'(x) > 0$；$0 < x < 2$ 时 $f'(x) < 0$；$x > 2$ 时 $f'(x) > 0$。
    
    故 $x=0$ 为极大值点，极大值 $f(0) = 1$；$x=2$ 为极小值点，极小值 $f(2) = -3$。

### 【例2】（最值问题）

求 $f(x) = x^3 - 3x$ 在 $[-2,2]$ 上的最大值和最小值。

??? note "解析"
    $f'(x) = 3x^2 - 3 = 3(x+1)(x-1)$，驻点 $x=-1,\;x=1$。
    
    $f(-1) = 2$，$f(1) = -2$，$f(-2) = -2$，$f(2) = 2$。
    
    比较得最大值 $2$，最小值 $-2$。

## 常见题型与技巧

| 题型 | 解法要点 |
|------|----------|
| 极值判断 | 求导→找驻点→判断变号 |
| 已知极值求参数 | $f'(x_0)=0$ 列方程，验证充分性 |
| 最值问题 | 比较极值和端点值 |
| 含参最值 | 分类讨论参数对单调性的影响 |

## 练习

!!! question "练习1"
    求 $f(x) = x^2 e^{-x}$ 的极值。

    ??? note "答案"
        $f'(x) = 2xe^{-x} - x^2e^{-x} = x(2-x)e^{-x}$。驻点 $x=0,\;x=2$。
        $f(0)=0$ 为极小值，$f(2)=4e^{-2}$ 为极大值。
