## 圆锥曲线综合题通法

1. **设直线**：常设 $y=kx+m$；若可能竖直，需单独讨论。
2. **联立方程**：与圆锥曲线方程联立，消去一个变量。
3. **判别式**：保证有两个交点，通常要求 $\Delta>0$。
4. **韦达定理**：设交点坐标为 $A(x_1,y_1),B(x_2,y_2)$，用 $x_1+x_2$、$x_1x_2$ 代替复杂根式。
5. **几何量代数化**：弦长、斜率、面积、距离、角度均转为坐标表达式。

## 常见高考题型

| 题型 | 关键词 | 解法要点 |
|------|--------|----------|
| 求轨迹方程 | 动点、距离关系 | 建立坐标，用定义或距离公式化简 |
| 弦长问题 | 过定点直线、弦长定值 | 联立后用弦长公式 |
| 中点弦问题 | 中点已知、求直线 | 点差法最高效 |
| 定点问题 | 直线/曲线恒过某点 | 写出含参方程，分离参数 |
| 定值问题 | 面积/斜率积/距离和不变 | 韦达定理消元化简 |
| 最值范围 | 参数变化求最大最小 | 建函数，配方或导数 |
