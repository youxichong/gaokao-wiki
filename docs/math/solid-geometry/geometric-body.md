# 空间几何体

**前置知识**：无

!!! note "考纲要求"
    了解棱柱、棱锥、棱台、圆柱、圆锥、圆台、球的结构特征；掌握常见几何体的表面积与体积公式；能识别三视图和展开图中的几何关系。

## 多面体

**棱柱**：有两个面互相平行，其余各面都是平行四边形，并且每相邻两个四边形的公共边互相平行。

**棱锥**：有一个面是多边形，其余各面都是有公共顶点的三角形。

**棱台**：用一个平行于棱锥底面的平面截棱锥，截面与底面之间的部分。

## 旋转体

| 几何体 | 生成方式 | 体积公式 |
|--------|----------|----------|
| 圆柱 | 矩形绕一边旋转 | $V = \pi r^2h$ |
| 圆锥 | 直角三角形绕直角边旋转 | $V = \frac{1}{3}\pi r^2h$ |
| 圆台 | 直角梯形绕高旋转 | $V = \frac{1}{3}\pi h(R^2 + Rr + r^2)$ |
| 球 | 半圆绕直径旋转 | $V = \frac{4}{3}\pi R^3$ |

## 表面积公式

| 几何体 | 侧面积 | 表面积 |
|--------|--------|--------|
| 圆柱 | $S_{侧}=2\pi rh$ | $S=2\pi r^2+2\pi rh$ |
| 圆锥 | $S_{侧}=\pi rl$ | $S=\pi r^2+\pi rl$ |
| 圆台 | $S_{侧}=\pi(R+r)l$ | $S=\pi R^2+\pi r^2+\pi(R+r)l$ |
| 球 | — | $S=4\pi R^2$ |

## 例题

### 【例1】（基础题）

一个圆锥的底面半径为 $3$，高为 $4$，求它的侧面积和体积。

??? note "解析"
    母线 $l=\sqrt{3^2+4^2}=5$。
    
    侧面积 $S_{侧}=\pi rl=15\pi$。
    
    体积 $V=\frac{1}{3}\pi r^2h=\frac{1}{3}\pi\cdot9\cdot4=12\pi$。

### 【例2】（综合题）

正三棱锥 $P-ABC$ 的底面边长为 $6$，侧棱 $PA=PB=PC=5$，求该棱锥的体积。

??? note "解析"
    正三棱锥顶点 $P$ 在底面中心 $O$ 的正上方。
    
    正三角形 $ABC$ 的外接圆半径 $OA=\frac{6}{\sqrt3}=2\sqrt3$。
    
    高 $PO=\sqrt{PA^2-OA^2}=\sqrt{25-12}=\sqrt{13}$。
    
    底面积 $S_{ABC}=\frac{\sqrt3}{4}\cdot6^2=9\sqrt3$。
    
    体积 $V=\frac13 S_{ABC}\cdot PO=\frac13\cdot9\sqrt3\cdot\sqrt{13}=3\sqrt{39}$。

## 常见题型与技巧

| 题型 | 解法要点 | 易错点 |
|------|----------|--------|
| 求体积/表面积 | 识别底面、高、母线 | 圆锥母线不等于高 |
| 三视图还原 | 先确定底面，再确定高度 | 误把视图长度当空间长度 |
| 截面问题 | 利用相似或体积比 | 截面与底面平行时比例为线性比 |
| 球与多面体 | 找球心和半径 | 内切球/外接球半径混淆 |

## 练习

!!! question "练习1"
    一个球的表面积为 $36\pi$，求它的体积。

    ??? note "答案"
        $4\pi R^2=36\pi$，$R=3$。体积 $V=\frac43\pi R^3=36\pi$。

!!! question "练习2"
    正方体棱长为 $2$，求其外接球半径。

    ??? note "答案"
        正方体外接球直径等于体对角线，$d=2\sqrt3$，故 $R=\sqrt3$。
