# 导数与单调性

**前置知识**：[导数的概念](concept.md)

!!! note "考纲要求"
    掌握利用导数判断函数单调性的方法；能根据导数符号确定函数的单调区间；理解单调性是研究函数极值和最值的基础。

## 定理

设函数 $f(x)$ 在区间 $(a,b)$ 内可导：

- 若 $\forall x \in (a,b),\; f'(x) > 0$，则 $f(x)$ 在 $(a,b)$ 内单调**递增**
- 若 $\forall x \in (a,b),\; f'(x) < 0$，则 $f(x)$ 在 $(a,b)$ 内单调**递减**
- 若 $\forall x \in (a,b),\; f'(x) = 0$，则 $f(x)$ 在 $(a,b)$ 内为常数

!!! warning "注意"
    $f'(x) > 0$ 是 $f(x)$ 单调递增的**充分不必要**条件。$f(x) = x^3$ 在 $x=0$ 处 $f'(0) = 0$，但 $f(x)$ 在 $\mathbb{R}$ 上单调递增。

**求单调区间的步骤**：
1. 求定义域
2. 求 $f'(x)$
3. 解 $f'(x) > 0$（递增区间）和 $f'(x) < 0$（递减区间）
4. 下结论

## 例题

### 【例1】（基础题）

求 $f(x) = x^3 - 3x$ 的单调区间。

??? note "解析"
    $f'(x) = 3x^2 - 3 = 3(x+1)(x-1)$
    
    令 $f'(x) > 0$：$x < -1$ 或 $x > 1$；令 $f'(x) < 0$：$-1 < x < 1$。
    
    故递增区间为 $(-\infty,-1)$ 和 $(1,+\infty)$，递减区间为 $(-1,1)$。

### 【例2】（含参问题）

已知 $f(x) = \frac{1}{3}x^3 - x^2 + ax$ 在 $\mathbb{R}$ 上单调递增，求 $a$ 的取值范围。

??? note "解析"
    $f'(x) = x^2 - 2x + a$。在 $\mathbb{R}$ 上单调递增，等价于 $f'(x) \geqslant 0$ 恒成立（且不恒为 $0$）。
    
    即 $\Delta = 4 - 4a \leqslant 0$，解得 $a \geqslant 1$。

## 常见题型与技巧

| 题型 | 特征 | 解法要点 |
|------|------|----------|
| 求单调区间 | 不含参函数 | 解 $f'(x) > 0$ 或 $< 0$ |
| 已知单调性求参数 | 函数在某区间单调 | 转化为 $f'(x) \geqslant 0$（或 $\leqslant 0$）恒成立 |
| 含参讨论单调性 | 参数影响导数符号 | 分类讨论判别式和根的大小 |

## 练习

!!! question "练习1"
    求 $f(x) = \ln x - x$ 的单调区间。

    ??? note "答案"
        定义域 $(0,+\infty)$，$f'(x) = \frac{1}{x} - 1 = \frac{1-x}{x}$。
        递增区间 $(0,1)$，递减区间 $(1,+\infty)$。
