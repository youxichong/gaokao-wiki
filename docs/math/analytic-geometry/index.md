# 解析几何

**前置知识**：[函数](../function/index.md)、[平面向量](../vector/index.md)

!!! note "考纲要求"
    解析几何在浙江新高考中约占 20 分，通常包括直线与圆的选填题、圆锥曲线解答题。核心是用代数方法研究几何对象：坐标、方程、交点、弦长、距离、斜率。

## 解题主线

```text
坐标建模 → 写出方程 → 联立消元 → 韦达定理 → 几何量转代数式
```

## 常用工具

- **弦长公式**：联立后用韦达定理计算
- **点差法**：处理中点弦问题
- **参数法**：用斜率或点坐标作为参数
- **判别式法**：判断交点个数和切线问题
