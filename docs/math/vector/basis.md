# 平面向量基本定理

**前置知识**：[向量概念与线性运算](concept.md)

!!! note "考纲要求"
    理解平面向量基本定理，掌握向量的正交分解及坐标表示；掌握向量坐标形式的加、减、数乘运算。

## 平面向量基本定理

若 $\vec{e}_1,\vec{e}_2$ 是同一平面内两个**不共线**的向量，则对该平面内任意向量 $\vec{a}$，存在唯一有序实数对 $(x,y)$，使

$$
\vec{a} = x\vec{e}_1 + y\vec{e}_2
$$

称 $\{\vec{e}_1,\vec{e}_2\}$ 为基底，$(x,y)$ 为 $\vec{a}$ 在基底下的坐标。

## 坐标运算

取正交基底 $\{\vec{i}, \vec{j}\}$（$\vec{i}=(1,0),\; \vec{j}=(0,1)$），设 $\vec{a} = (x_1, y_1)$，$\vec{b} = (x_2, y_2)$：

| 运算 | 坐标形式 |
|------|----------|
| 加法 | $\vec{a} + \vec{b} = (x_1 + x_2,\; y_1 + y_2)$ |
| 减法 | $\vec{a} - \vec{b} = (x_1 - x_2,\; y_1 - y_2)$ |
| 数乘 | $\lambda\vec{a} = (\lambda x_1,\; \lambda y_1)$ |
| 模 | $|\vec{a}| = \sqrt{x_1^2 + y_1^2}$ |

**中点公式**：$A(x_1,y_1),\; B(x_2,y_2)$ 的中点 $M$ 坐标为 $\displaystyle\left(\frac{x_1+x_2}{2}, \frac{y_1+y_2}{2}\right)$。

## 例题

### 【例1】（基础题）

已知 $\vec{a} = (2,1)$，$\vec{b} = (-1,3)$，求 $\vec{a} + \vec{b}$ 和 $3\vec{a} - 2\vec{b}$。

??? note "解析"
    $\vec{a} + \vec{b} = (2+(-1), 1+3) = (1,4)$
    
    $3\vec{a} - 2\vec{b} = (6,3) - (-2,6) = (8,-3)$。
