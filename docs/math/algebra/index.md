# 代数基础

**前置知识**：无

!!! note "考纲要求"
    集合与常用逻辑用语、不等式、复数是浙江新高考数学的基础模块，在试卷中多以选择题、填空题形式出现，通常与函数、数列等专题交叉命题。集合与逻辑约 5 分，不等式约 3 分，复数约 5 分。

## 模块综述

代数基础是高中数学的**工具性模块**，为函数、解析几何、数列、向量等所有后续专题提供基本语言和推理方法。

| 子专题 | 前置知识 | 核心内容 | 高考地位 |
|--------|----------|----------|----------|
| [集合](set.md) | 无 | 集合的概念与运算、子集与 Venn 图 | 必考 1 道选择/填空 |
| [常用逻辑用语](logic.md) | [集合](set.md) | 命题、充分/必要条件、量词 | 常与不等式结合考查 |
| [不等式](inequality.md) | [集合](set.md) | 不等式性质、一元二次不等式、基本不等式 | 工具性质强，贯穿全卷 |
| [复数](complex-number.md) | 无 | 复数运算、几何意义、共轭与模 | 必考 1 道选择/填空 |

## 知识结构

```text
集合 ──→ 逻辑用语（命题、条件、量词）
  │
  ├──→ 不等式的性质与解法
  │       │
  │       └──→ 基本不等式（求最值工具）
  │
  └──→ 复数（数系的扩充）
```

## 常见综合方式

1. **集合与逻辑**：用集合的包含关系求解充分/必要条件中的参数范围。
2. **不等式与函数**：一元二次不等式对应二次函数图像、基本不等式用于求函数最值。
3. **不等式与数列**：基本不等式用于数列求和的最值问题。
4. **复数与三角**：复数的三角形式与三角恒等变换结合（选考/强基）。

## 复习建议

- **集合**：重点掌握 Venn 图法解集合运算题，注意空集讨论。
- **逻辑用语**：分清充分条件与必要条件的方向，"小范围推大范围"是充要。
- **不等式**：基本不等式配凑技巧需要大量练习，是高三复习的重要基本功。
- **复数**：掌握四则运算即可，其中除法是高频考点。
