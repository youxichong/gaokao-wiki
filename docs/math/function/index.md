# 函数

**前置知识**：[代数基础](../algebra/index.md)

!!! note "考纲要求"
    函数是高中数学的主线，覆盖约 25 分。在浙江新高考中，函数概念与性质、指数函数、对数函数、幂函数、函数零点与方程、导数及其应用均为必考内容。导数解答题（12 分）是全卷最具区分度的题目之一。

## 模块总览

| 子专题 | 前置知识 | 核心内容 | 高考地位 |
|--------|----------|----------|----------|
| [函数概念与基本性质](concept.md) | [集合](../algebra/set.md) | 定义域、值域、单调性、奇偶性、周期性 | 选填高频考点 |
| [幂函数](power.md) | [函数概念](concept.md) | $y = x^\alpha$ 的图像与性质 | 了解，常以比较大小出现 |
| [指数函数](exponential.md) | [函数概念](concept.md) | $y = a^x$ 的图像与性质、指数运算 | 选择/填空 1 道 |
| [对数函数](logarithmic.md) | [指数函数](exponential.md) | $y = \log_a x$、对数运算、换底公式 | 选择/填空 1 道 |
| [函数零点与方程](zero-point.md) | [函数概念](concept.md) | 零点定理、二分法、零点分布 | 选填，常与导数综合 |
| [导数](derivative/index.md) | [函数概念](concept.md) | 导数计算、单调性、极值、应用 | 解答题压轴 12 分 |

## 学习路径

```text
函数概念 → 幂函数 → 指数函数 → 对数函数
    │                              │
    └─────────→ 零点 ←──────────────┘
         │
         └──→ 导数 → 单调性 → 极值 → 应用
```
