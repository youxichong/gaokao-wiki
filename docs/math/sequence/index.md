# 数列

**前置知识**：[函数](../function/index.md)

!!! note "考纲要求"
    数列在浙江新高考中约占 10 分，通常有 1 道选填和 1 道解答题。核心为等差、等比数列的通项与求和，以及递推关系与求和方法的综合运用。

## 模块总览

| 子专题 | 前置知识 | 核心内容 | 高考地位 |
|--------|----------|----------|----------|
| [等差数列](arithmetic.md) | 无 | 通项公式、等差中项、前 $n$ 项和 | 选填+解答 |
| [等比数列](geometric.md) | 无 | 通项公式、等比中项、前 $n$ 项和 | 选填+解答 |
| [递推数列](recurrence.md) | [等差](arithmetic.md)、[等比](geometric.md) | 常见递推类型及求通项方法 | 解答题核心 |
| [数列求和](summation.md) | [等差](arithmetic.md)、[等比](geometric.md) | 裂项相消、错位相减、分组求和 | 解答题核心 |

## 学习路径

```text
等差数列 ─┐
           ├──→ 递推数列 → 数列求和
等比数列 ─┘
```
