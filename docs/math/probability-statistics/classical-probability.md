# 古典概型

**前置知识**：[统计抽样](sampling.md)、[计数原理](counting/index.md)

!!! note "考纲要求"
    理解随机事件、样本空间、古典概型的概念；掌握古典概型概率公式；能结合排列组合解决等可能事件的概率问题。

## 基本概念

**随机试验**：在相同条件下可重复进行，结果不止一个，但试验前不能确定具体结果的试验。

**样本点**：随机试验的每一种可能结果。

**样本空间**：所有样本点组成的集合，记作 $\Omega$。

**随机事件**：样本空间的子集，通常记作 $A,B$。

## 事件关系与运算

| 关系/运算 | 记法 | 含义 |
|-----------|------|------|
| 包含 | $A\subseteq B$ | $A$ 发生必导致 $B$ 发生 |
| 并事件 | $A\cup B$ | $A$ 或 $B$ 至少一个发生 |
| 交事件 | $A\cap B$ | $A$ 与 $B$ 同时发生 |
| 对立事件 | $\overline{A}$ | $A$ 不发生 |
| 互斥事件 | $A\cap B=\varnothing$ | $A,B$ 不能同时发生 |

## 概率性质

- $0\leq P(A)\leq1$
- $P(\Omega)=1$，$P(\varnothing)=0$
- 若 $A,B$ 互斥，则 $P(A\cup B)=P(A)+P(B)$
- $P(\overline{A})=1-P(A)$
- 一般加法公式：$P(A\cup B)=P(A)+P(B)-P(A\cap B)$

## 古典概型

若随机试验满足：
1. 样本空间中样本点有限；
2. 每个样本点发生的可能性相等；

则称为古典概型。

古典概型概率公式：

$$
P(A)=\frac{A\text{ 包含的样本点个数}}{\Omega\text{ 中样本点总数}}
$$

## 例题

### 【例1】（基础题）

掷一枚均匀骰子一次，求出现点数不小于 $5$ 的概率。

??? note "解析"
    样本空间 $\Omega=\{1,2,3,4,5,6\}$，共 $6$ 个等可能结果。
    
    事件 $A=\{5,6\}$，共 $2$ 个结果。
    
    所以 $P(A)=\frac{2}{6}=\frac13$。

### 【例2】（高质量综合题）

从数字 $1,2,3,4,5$ 中不放回地任取 $3$ 个数字组成一个三位数，求该三位数为偶数的概率。

??? note "解析"
    所有三位数个数为 $A_5^3=5\times4\times3=60$。
    
    要为偶数，个位必须为 $2$ 或 $4$，有 $2$ 种选法。
    
    个位确定后，百位和十位从剩余 $4$ 个数字中有序选 $2$ 个，有 $A_4^2=12$ 种。
    
    有利结果数为 $2\times12=24$。
    
    所以概率 $P=\frac{24}{60}=\frac25$。

### 【例3】（对立事件）

袋中有 $4$ 个红球、$3$ 个白球、$2$ 个黑球，从中任取 $3$ 个球，求至少取到 $1$ 个红球的概率。

??? note "解析"
    总取法：$C_9^3=84$。
    
    至少取到 $1$ 个红球的对立事件是“没有红球”，即从 $5$ 个非红球中取 $3$ 个：$C_5^3=10$。
    
    所以 $P=1-\frac{10}{84}=\frac{37}{42}$。

## 常见题型与技巧

| 题型 | 解法要点 | 易错点 |
|------|----------|--------|
| 直接古典概型 | 数清总数和有利数 | 总数是否等可能 |
| 至少/至多 | 常用对立事件 | 对立事件写错 |
| 抽取问题 | 区分有序/无序、放回/不放回 | 排列组合混用 |
| 几何约束概率 | 先转化为计数问题 | 样本空间遗漏 |

## 练习

!!! question "练习1"
    从 $1,2,3,4,5,6$ 中任取两个不同数字，求它们之和为偶数的概率。

    ??? note "答案"
        总取法 $C_6^2=15$。和为偶数要求同奇偶：奇数 $1,3,5$ 中取 2 个有 $C_3^2=3$ 种，偶数 $2,4,6$ 中取 2 个有 $C_3^2=3$ 种。有利数 $6$，概率 $\frac{6}{15}=\frac25$。
