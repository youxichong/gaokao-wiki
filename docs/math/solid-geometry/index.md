# 立体几何

**前置知识**：[平面向量](../vector/index.md)、[三角函数](../trigonometry/index.md)

!!! note "考纲要求"
    立体几何在浙江新高考中约占 15 分，通常包括 1 道选填和 1 道解答题。核心是空间几何体的结构特征、点线面位置关系、空间向量法求角与距离。

## 模块总览

| 子专题 | 前置知识 | 核心内容 | 高考地位 |
|--------|----------|----------|----------|
| [空间几何体](geometric-body.md) | 无 | 柱、锥、台、球的结构与体积表面积 | 选填基础题 |
| [点线面位置关系](position-relation.md) | [空间几何体](geometric-body.md) | 平行、垂直的判定与性质 | 证明题基础 |
| [空间向量与立体几何](space-vector.md) | [平面向量](../vector/index.md) | 空间坐标、法向量、线面角、二面角 | 解答题核心工具 |
| [空间角与距离](angle-distance.md) | [空间向量](space-vector.md) | 异面直线角、线面角、二面角、点面距 | 解答题高频 |

## 学习路径

```text
空间几何体 → 点线面位置关系 → 空间向量建系
       │              │              │
       └──────────────┴──→ 角与距离计算
```

## 解题总策略

1. **能建系就建系**：高考解答题中，空间向量法稳定、可操作、少依赖空间想象。
2. **先证垂直再建系**：找到互相垂直的棱或辅助线，可显著简化坐标。
3. **几何法保留直觉**：选填题中，平行垂直性质、截面、体积常比纯计算更快。
