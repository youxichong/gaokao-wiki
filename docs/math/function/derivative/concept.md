# 导数的概念

**前置知识**：[函数概念与基本性质](../concept.md)

!!! note "考纲要求"
    理解导数概念及其几何意义；掌握基本初等函数的导数公式；掌握导数的四则运算法则；理解复合函数的求导法则。

## 定义

**导数的定义**：函数 $y = f(x)$ 在 $x = x_0$ 处的导数定义为

$$
f'(x_0) = \lim_{\Delta x \to 0} \frac{f(x_0 + \Delta x) - f(x_0)}{\Delta x}
$$

若该极限存在，则称 $f(x)$ 在 $x_0$ 处可导。

**导函数**：若 $f(x)$ 在区间 $(a,b)$ 内每一点都可导，则 $f'(x)$ 称为导函数。

## 几何意义

导数 $f'(x_0)$ 表示曲线 $y = f(x)$ 在点 $(x_0, f(x_0))$ 处切线的**斜率**。

切线方程：$y - f(x_0) = f'(x_0)(x - x_0)$

## 基本初等函数的导数公式

| 函数 | 导数 |
|------|------|
| $f(x) = C$（常数） | $f'(x) = 0$ |
| $f(x) = x^n$（$n \in \mathbb{R}$） | $f'(x) = nx^{n-1}$ |
| $f(x) = \sin x$ | $f'(x) = \cos x$ |
| $f(x) = \cos x$ | $f'(x) = -\sin x$ |
| $f(x) = a^x$ | $f'(x) = a^x \ln a$ |
| $f(x) = e^x$ | $f'(x) = e^x$ |
| $f(x) = \log_a x$ | $f'(x) = \frac{1}{x\ln a}$ |
| $f(x) = \ln x$ | $f'(x) = \frac{1}{x}$ |

## 求导法则

1. **和差**：$[f(x) \pm g(x)]' = f'(x) \pm g'(x)$
2. **积**：$[f(x)g(x)]' = f'(x)g(x) + f(x)g'(x)$
3. **商**：$\left[\frac{f(x)}{g(x)}\right]' = \frac{f'(x)g(x) - f(x)g'(x)}{[g(x)]^2} \quad (g(x) \neq 0)$
4. **复合函数**：$[f(g(x))]' = f'(g(x)) \cdot g'(x)$（链式法则）

## 例题

### 【例1】（基础题）

求 $f(x) = x^3 + 2x^2 - 5x + 1$ 在 $x = 1$ 处的导数。

??? note "解析"
    $f'(x) = 3x^2 + 4x - 5$，$f'(1) = 3 + 4 - 5 = 2$。

### 【例2】（切线问题）

求曲线 $y = x^3 - 3x + 2$ 在点 $(0,2)$ 处的切线方程。

??? note "解析"
    $y' = 3x^2 - 3$，$y'(0) = -3$。
    
    切线方程：$y - 2 = -3(x - 0)$，即 $y = -3x + 2$。

## 常见题型与技巧

| 题型 | 解法要点 |
|------|----------|
| 求导数值 | 先求导函数再代入 |
| 求切线方程 | 利用 $k = f'(x_0)$ 和点斜式 |
| 过某点的切线 | 设切点 $(x_0, f(x_0))$ 后列方程求解 |

## 练习

!!! question "练习1"
    求 $f(x) = \frac{x^2 - 1}{x + 2}$ 的导数。

    ??? note "答案"
        $f'(x) = \frac{(2x)(x+2) - (x^2-1)}{(x+2)^2} = \frac{x^2 + 4x + 1}{(x+2)^2}$。
