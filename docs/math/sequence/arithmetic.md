# 等差数列

**前置知识**：无

!!! note "考纲要求"
    理解等差数列的定义，掌握通项公式与前 $n$ 项和公式；理解等差中项的概念；掌握等差数列的基本性质。

## 定义

若数列 $\{a_n\}$ 满足 $a_{n+1} - a_n = d$（常数），则称 $\{a_n\}$ 为等差数列，$d$ 为公差。

## 通项公式

$$
a_n = a_1 + (n-1)d = a_m + (n-m)d
$$

## 等差中项

若 $a, A, b$ 成等差数列，则 $A = \frac{a+b}{2}$。

## 前 $n$ 项和

$$
S_n = \frac{n(a_1 + a_n)}{2} = na_1 + \frac{n(n-1)}{2}d
$$

## 常用性质

- 若 $m + n = p + q$，则 $a_m + a_n = a_p + a_q$
- $S_n$ 是关于 $n$ 的二次函数（无常数项）：$S_n = \frac{d}{2}n^2 + (a_1 - \frac{d}{2})n$
- 下标等距取项仍构成等差数列

## 例题

### 【例1】（基础题）

等差数列 $\{a_n\}$ 中，$a_1 = 3$，$a_4 = 9$，求 $a_n$ 和 $S_6$。

??? note "解析"
    $a_4 = a_1 + 3d$，$9 = 3 + 3d$，$d = 2$
    
    $a_n = 3 + (n-1) \times 2 = 2n + 1$
    
    $S_6 = 6 \times 3 + \frac{6 \times 5}{2} \times 2 = 18 + 30 = 48$
