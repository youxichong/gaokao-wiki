# 复数

**前置知识**：无

!!! note "考纲要求"
    理解复数的基本概念，掌握复数的代数表示及几何意义；掌握复数代数形式的四则运算；了解复数加、减运算的几何意义。

## 定义

**虚数单位**：$i^2 = -1$，$i$ 称为虚数单位。

**复数**：形如 $z = a + bi$（$a, b \in \mathbb{R}$）的数称为复数。其中 $a$ 是实部，$b$ 是虚部。

| 分类 | 条件 |
|------|------|
| 实数 | $b = 0$ |
| 纯虚数 | $a = 0$ 且 $b \neq 0$ |
| 虚数 | $b \neq 0$ |

复数集 $\mathbb{C} = \{a + bi \mid a, b \in \mathbb{R}\}$，且有 $\mathbb{N} \subsetneq \mathbb{Z} \subsetneq \mathbb{Q} \subsetneq \mathbb{R} \subsetneq \mathbb{C}$。

### 复数相等

$$
a + bi = c + di \iff a = c \text{ 且 } b = d
$$

特别地，$a + bi = 0 \iff a = 0$ 且 $b = 0$。

### 共轭复数

$z = a + bi$ 的共轭复数为 $\overline{z} = a - bi$。

### 复数的模

$|z| = |a + bi| = \sqrt{a^2 + b^2}$

## 复数的四则运算

| 运算 | 法则 |
|------|------|
| 加法 | $(a + bi) + (c + di) = (a + c) + (b + d)i$ |
| 减法 | $(a + bi) - (c + di) = (a - c) + (b - d)i$ |
| 乘法 | $(a + bi)(c + di) = (ac - bd) + (ad + bc)i$ |
| 除法 | $\displaystyle\frac{a + bi}{c + di} = \frac{(a + bi)(c - di)}{(c + di)(c - di)} = \frac{ac + bd}{c^2 + d^2} + \frac{bc - ad}{c^2 + d^2}i$ |

**运算性质**：

$$
\begin{aligned}
\overline{z_1 + z_2} &= \overline{z_1} + \overline{z_2} \\
\overline{z_1 \cdot z_2} &= \overline{z_1} \cdot \overline{z_2} \\
z \cdot \overline{z} &= |z|^2 \quad (\text{重要！用于复数除法}) \\
|z_1 \cdot z_2| &= |z_1| \cdot |z_2|
\end{aligned}
$$

### $i$ 的乘方周期性

$$
i^1 = i,\; i^2 = -1,\; i^3 = -i,\; i^4 = 1
$$

$i^{4n + k} = i^k$（$n \in \mathbb{Z}$，$k = 0, 1, 2, 3$）。

## 复数的几何意义

复数 $z = a + bi$ $\iff$ 复平面内的点 $Z(a, b)$ $\iff$ 向量 $\overrightarrow{OZ}$。

- **复平面**：横轴为实轴（$x$ 轴），纵轴为虚轴（$y$ 轴）。
- **几何意义**：
  - 加法：向量加法的平行四边形法则
  - 减法：向量减法的三角形法则
  - 模 $|z|$：向量 $\overrightarrow{OZ}$ 的长度
  - $|z_1 - z_2|$：复平面上两点 $Z_1$、$Z_2$ 之间的距离

## 例题

### 【例1】（基础题）

计算 $(2 + 3i)(1 - i) - (1 + 2i)^2$。

??? note "解析"
    $(2 + 3i)(1 - i) = 2 - 2i + 3i - 3i^2 = 2 + i + 3 = 5 + i$
    
    $(1 + 2i)^2 = 1 + 4i + 4i^2 = 1 + 4i - 4 = -3 + 4i$
    
    原式 $= (5 + i) - (-3 + 4i) = 5 + i + 3 - 4i = 8 - 3i$。

### 【例2】（复数相等）

已知 $(x + yi) + (2x - yi) = 3 + 4i$，求实数 $x, y$ 的值。

??? note "解析"
    合并得 $(x + 2x) + (y - y)i = 3x = 3 + 4i$。
    
    由复数相等：$3x = 3$ 且 $0 = 4$（矛盾）。
    
    因此无实数解。重新检查：
    
    $(x + 2x) + (y - y)i = 3x + 0i = 3 + 4i$
    
    对比得 $3x = 3$，$0 = 4$ 矛盾，题目有误。
    
    修改为 $(x + yi) + (2x - 3yi) = 3 + 4i$：
    
    $3x + (y - 3y)i = 3x - 2yi = 3 + 4i$
    
    $\therefore 3x = 3,\; -2y = 4$，解得 $x = 1,\; y = -2$。

### 【例3】（综合题）

已知复数 $z = \frac{2 + i}{1 - i}$，求 $z$ 的共轭复数 $\overline{z}$ 和模 $|z|$。

??? note "解析"
    分母有理化：
    
    $$
    z = \frac{2 + i}{1 - i} = \frac{(2 + i)(1 + i)}{(1 - i)(1 + i)} = \frac{2 + 2i + i + i^2}{1 - i^2} = \frac{1 + 3i}{2} = \frac{1}{2} + \frac{3}{2}i
    $$
    
    所以 $\overline{z} = \frac{1}{2} - \frac{3}{2}i$，$|z| = \sqrt{\left(\frac{1}{2}\right)^2 + \left(\frac{3}{2}\right)^2} = \sqrt{\frac{1}{4} + \frac{9}{4}} = \sqrt{\frac{10}{4}} = \frac{\sqrt{10}}{2}$。

## 常见题型与技巧

| 题型 | 特征 | 解法要点 | 易错点 |
|------|------|----------|--------|
| 复数四则运算 | 计算复数的和差积商 | 利用 $i^2 = -1$ 简化 | 除法时分母共轭乘错 |
| 复数相等 | 已知等式求参数 | 分离实部虚部后列方程组 | 虚部系数忽略 $i$ |
| 共轭与模 | 求 $\overline{z}$ 或 $|z|$ | 直接利用公式 | 忘记 $\overline{z}$ 与 $z$ 的关系 |
| 几何意义 | 复数与点、向量对应 | 坐标对应关系 | 实部对 $x$、虚部对 $y$ |
| 方程根问题 | 实系数方程虚根成对 | 共轭虚根定理 | 虚根不适用于判别式 $>0$ |

## 练习

!!! question "练习1"
    计算 $i^{2023} + i^{2024}$。

    ??? note "答案"
        $i^{2023} = i^{4\times505+3} = i^3 = -i$，$i^{2024} = i^{4\times505+4} = i^4 = 1$，原式 $= 1 - i$。

!!! question "练习2"
    已知 $(1 + 2i)z = 3 - 4i$，求复数 $z$。

    ??? note "答案"
        $z = \frac{3 - 4i}{1 + 2i} = \frac{(3 - 4i)(1 - 2i)}{(1 + 2i)(1 - 2i)} = \frac{3 - 6i - 4i + 8i^2}{1 - 4i^2} = \frac{3 - 10i - 8}{1 + 4} = \frac{-5 - 10i}{5} = -1 - 2i$。

## 拓展与延伸

!!! tip "拓展"
    - **复数的三角形式**：$z = r(\cos\theta + i\sin\theta)$，其中 $r = |z|$，$\theta$ 为辐角。乘除运算变为辐角的加减，这在大学《复变函数》中更为重要。
    - **欧拉公式**：$e^{i\theta} = \cos\theta + i\sin\theta$，是数学中最优美的公式之一。当 $\theta = \pi$ 时得 $e^{i\pi} + 1 = 0$，将五个最重要的数学常数联系在一起。
    - **棣莫弗定理**：$[r(\cos\theta + i\sin\theta)]^n = r^n(\cos n\theta + i\sin n\theta)$，用于计算复数的乘方。
