# 概率统计

**前置知识**：[集合](../algebra/set.md)、[函数](../function/index.md)

!!! note "考纲要求"
    概率统计在浙江新高考中约占 15 分，常见形式为选填题和解答题。重点包括计数原理、古典概型、条件概率、随机变量分布列、二项分布、正态分布、抽样与回归分析。

## 模块总览

| 子专题 | 核心内容 | 高考地位 |
|--------|----------|----------|
| [统计抽样](sampling.md) | 样本、频率分布、均值方差、百分位数 | 选填/解答基础 |
| [计数原理](counting/index.md) | 分类加法、分步乘法、排列组合、二项式定理 | 概率计算基础 |
| [古典概型](classical-probability.md) | 等可能事件、互斥对立、概率公式 | 选填高频 |
| [条件概率与全概率公式](conditional-probability.md) | 条件概率、独立性、全概率公式、贝叶斯公式 | 新教材重点 |
| [随机变量](random-variable/index.md) | 分布列、期望、方差 | 解答题核心 |
| [成对数据统计分析](regression.md) | 相关系数、线性回归、独立性检验 | 应用题高频 |

## 学习路径

```text
统计抽样 → 概率模型 → 条件概率 → 随机变量 → 分布与期望
    │
    └──→ 成对数据 → 相关与回归

计数原理 → 排列组合 → 二项式定理 → 古典概型
```

## 解题策略

- **先辨模型**：古典概型、条件概率、独立重复试验、超几何分布、二项分布要先区分。
- **再列事件**：复杂概率题先定义事件，再用公式，避免口算混乱。
- **最后检查范围**：概率必须在 $[0,1]$，期望应符合实际量纲。
