# 平面向量

**前置知识**：[三角函数](../trigonometry/index.md)

!!! note "考纲要求"
    平面向量在浙江新高考中约占 5 分，通常以选填题形式出现，也常与立体几何（空间向量）、解析几何结合考查。核心为向量的线性运算、数量积及其应用。
