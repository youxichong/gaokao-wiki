# 抛物线

**前置知识**：[椭圆](ellipse.md)

!!! note "考纲要求"
    掌握抛物线的定义、标准方程和几何性质；理解焦点、准线、通径；能处理直线与抛物线的交点、焦点弦和切线问题。

## 定义

平面内到一个定点 $F$ 和一条定直线 $l$（$F\notin l$）距离相等的点的轨迹叫做抛物线。定点 $F$ 为焦点，定直线 $l$ 为准线。

## 标准方程与性质

| 方程 | 焦点 | 准线 | 开口方向 |
|------|------|------|----------|
| $y^2=2px\;(p>0)$ | $(\frac p2,0)$ | $x=-\frac p2$ | 向右 |
| $y^2=-2px\;(p>0)$ | $(-\frac p2,0)$ | $x=\frac p2$ | 向左 |
| $x^2=2py\;(p>0)$ | $(0,\frac p2)$ | $y=-\frac p2$ | 向上 |
| $x^2=-2py\;(p>0)$ | $(0,-\frac p2)$ | $y=\frac p2$ | 向下 |

!!! note "教材常用形式"
    也常写作 $y^2=2px$。若用 $y^2=4ax$，则焦点为 $(a,0)$，准线为 $x=-a$。

## 焦点弦性质

对 $y^2=2px$，过焦点的直线与抛物线交于 $A,B$：

- 通径长：$2p$
- 若直线斜率为 $k$，焦点弦长常可通过联立方程与韦达定理求得

## 例题

### 【例1】（基础题）

求抛物线 $y^2=8x$ 的焦点和准线。

??? note "解析"
    与 $y^2=2px$ 对比，$2p=8$，$p=4$。
    
    焦点为 $(\frac p2,0)=(2,0)$，准线为 $x=-2$。

### 【例2】（高质量综合题）

已知抛物线 $C:y^2=4x$，直线 $l:y=kx+1$ 与 $C$ 交于 $A,B$ 两点。若 $AB$ 的中点横坐标为 $3$，求 $k$。

??? note "解析"
    联立 $y=kx+1$ 与 $y^2=4x$：
    $$
    (kx+1)^2=4x
    $$
    $$
    k^2x^2+(2k-4)x+1=0
    $$
    设两交点横坐标为 $x_1,x_2$，则
    $$
    x_1+x_2=\frac{4-2k}{k^2}
    $$
    中点横坐标为 $3$，故 $\frac{x_1+x_2}{2}=3$，即 $x_1+x_2=6$。
    
    所以 $\frac{4-2k}{k^2}=6$，得 $3k^2+k-2=0$。
    
    解得 $k=\frac23$ 或 $k=-1$。
    
    还需判别式 $\Delta>0$：$(2k-4)^2-4k^2=16-16k>0$，即 $k<1$，两解均符合。

## 常见题型与技巧

| 题型 | 解法要点 |
|------|----------|
| 求焦点准线 | 对照标准方程确定 $p$ |
| 焦点弦 | 联立方程，韦达定理求弦长 |
| 中点弦 | 点差法或联立韦达 |
| 切线问题 | 判别式为 $0$ 或导数法 |

## 练习

!!! question "练习1"
    抛物线焦点为 $(3,0)$，求其标准方程和准线。

    ??? note "答案"
        焦点为 $(\frac p2,0)=(3,0)$，$p=6$。方程 $y^2=12x$，准线 $x=-3$。
