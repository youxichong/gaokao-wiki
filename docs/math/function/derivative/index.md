# 导数

**前置知识**：[函数概念与基本性质](../concept.md)

!!! note "考纲要求"
    导数及其应用是高考解答题的压轴题，通常 12 分。要求理解导数的几何意义，掌握基本初等函数的导数公式和求导法则，能利用导数研究函数的单调性、极值与最值，并能解决实际问题与不等式证明。
