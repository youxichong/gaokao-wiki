## 知识框架

本部分采用 **OI-Wiki 风格** 组织知识点：每个知识点独立成页，包含定义、定理、例题、常见题型与练习，并标注前置知识依赖关系。

| 模块 | 核心知识点 | 高考分值占比（估算） |

### 学习路径图

```text
集合/逻辑 --→ 函数 --→ 导数 --┬--→ 解析几何
            │                  │
不等数 ------┘                  └──→ 数列

三角函数 --→ 解三角形 --→ 向量 --→ 立体几何（空间向量）

计数原理 --→ 概率 --→ 随机变量 --→ 统计回归
```
