# 组合

**前置知识**：[排列](permutation.md)

!!! note "考纲要求"
    理解组合的概念；掌握组合数公式及性质；能处理选取、分组、至少至多类计数问题。

## 定义

从 $n$ 个不同元素中取出 $m$ 个元素组成一组，不考虑顺序，叫做一个组合。

组合数记为 $C_n^m$ 或 $\binom{n}{m}$。

## 组合数公式

$$
C_n^m=\frac{A_n^m}{m!}=\frac{n!}{m!(n-m)!}
$$

## 组合数性质

$$
C_n^m=C_n^{n-m},
\qquad
C_n^m+C_n^{m+1}=C_{n+1}^{m+1}
$$

## 例题

### 【例1】（基础题）

从 8 名同学中选 3 人参加比赛，共有多少种选法？

??? note "解析"
    不考虑顺序，为组合问题：$C_8^3=56$。

### 【例2】（高质量综合题）

从 6 名男生、4 名女生中选 4 人组成小组，要求至少有 1 名女生，共有多少种选法？

??? note "解析"
    方法一：总数减去全男。
    
    总选法 $C_{10}^4=210$；全男选法 $C_6^4=15$。
    
    故至少 1 名女生的选法为 $210-15=195$。
    
    方法二：按女生人数分类也可：$C_4^1C_6^3+C_4^2C_6^2+C_4^3C_6^1+C_4^4C_6^0=195$。

## 常见题型与技巧

| 题型 | 方法 |
|------|------|
| 至少问题 | 总数减反面更快 |
| 分组问题 | 注意是否平均分组，平均分组要除以组间排列 |
| 分配问题 | 若不同对象给不同盒子，通常先分组再排列 |

## 练习

!!! question "练习1"
    从 5 名男生、5 名女生中选 4 人，要求男女各 2 人，共有多少种？

    ??? note "答案"
        $C_5^2C_5^2=10\times10=100$。
