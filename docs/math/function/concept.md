# 函数概念与基本性质

**前置知识**：[集合](../algebra/set.md)

!!! note "考纲要求"
    理解函数的概念，了解函数的三要素（定义域、对应关系、值域）；理解函数的单调性、奇偶性、周期性及其几何意义；掌握函数的最值与图像变换。

## 定义

**函数**：设 $A, B$ 是非空实数集，如果按照某种确定的对应关系 $f$，对于集合 $A$ 中的任意一个数 $x$，在集合 $B$ 中都有唯一确定的数 $y$ 与之对应，则称 $f: A \to B$ 为从 $A$ 到 $B$ 的一个函数，记作

$$
y = f(x), \quad x \in A
$$

其中 $x$ 称为**自变量**，$y$ 称为**因变量**。

**函数的三要素**：

| 要素 | 定义 | 表示 |
|------|------|------|
| 定义域 | 自变量 $x$ 的取值范围 | 集合 $A$ |
| 对应关系 | 从 $x$ 到 $y$ 的规则 | $f$ |
| 值域 | 函数值 $y$ 的集合 | $\{f(x) \mid x \in A\}$ |

**函数的表示法**：

1. **解析法**：$y = f(x)$（公式形式）
2. **列表法**：用表格列出部分对应值
3. **图像法**：在平面直角坐标系中绘出曲线

### 分段函数

用多个解析式表示的函数，在不同区间上有不同的对应关系：

$$
f(x) = \begin{cases}
f_1(x), & x \in D_1 \\
f_2(x), & x \in D_2 \\
\vdots
\end{cases}
$$

## 函数的单调性

对于定义域 $I$ 内某个区间 $D$ 上的任意两个自变量 $x_1, x_2$：

- **增函数**：若 $x_1 < x_2$ 时 $f(x_1) < f(x_2)$，则 $f$ 在 $D$ 上单调递增
- **减函数**：若 $x_1 < x_2$ 时 $f(x_1) > f(x_2)$，则 $f$ 在 $D$ 上单调递减

**单调性的判断方法**：

| 方法 | 步骤 |
|------|------|
| 定义法 | 任取 $x_1 < x_2$，作差 $f(x_1)-f(x_2)$ 并判断符号 |
| 导数法 | $f'(x) > 0$ 则递增，$f'(x) < 0$ 则递减（后文详述） |
| 图像法 | 观察图像走向 |

## 函数的奇偶性

设 $f(x)$ 的定义域 $I$ 关于原点对称：

- **奇函数**：$\forall x \in I,\; f(-x) = -f(x)$，图像关于原点对称
- **偶函数**：$\forall x \in I,\; f(-x) = f(x)$，图像关于 $y$ 轴对称

**性质**：

- 奇函数在 $x=0$ 处有定义时必有 $f(0) = 0$
- 奇（偶）函数在对称区间上的单调性一致（相反）
- 两个奇函数的乘积是偶函数

## 函数的周期性

若存在非零常数 $T$，使得 $\forall x \in I$ 有 $f(x + T) = f(x)$，则称 $f$ 为**周期函数**，$T$ 为函数的周期。

最小正周期：所有正周期中最小的正数。

**常见周期函数**：

| 函数 | 最小正周期 |
|------|-----------|
| $\sin x$ | $2\pi$ |
| $\cos x$ | $2\pi$ |
| $\tan x$ | $\pi$ |
| $|\sin x|$ | $\pi$ |

## 例题

### 【例1】（基础题）

求函数 $f(x) = \frac{\sqrt{x + 2}}{x - 1}$ 的定义域。

??? note "解析"
    需同时满足：
    $$
    \begin{cases}
    x + 2 \geqslant 0 \\
    x - 1 \neq 0
    \end{cases}
    \Rightarrow
    \begin{cases}
    x \geqslant -2 \\
    x \neq 1
    \end{cases}
    $$
    
    故定义域为 $[-2, 1) \cup (1, +\infty)$。

### 【例2】（单调性与奇偶性）

已知 $f(x) = x^2 - 2|x| + 1$，判断 $f(x)$ 的奇偶性，并求其单调区间。

??? note "解析"
    $f(-x) = (-x)^2 - 2|-x| + 1 = x^2 - 2|x| + 1 = f(x)$，故为偶函数。
    
    当 $x \geqslant 0$ 时，$f(x) = x^2 - 2x + 1 = (x - 1)^2$，在 $[0,1]$ 上递减，在 $[1,+\infty)$ 上递增。
    
    由偶函数对称性，得单调递增区间：$[-1,0]$ 和 $[1,+\infty)$；单调递减区间：$(-\infty,-1]$ 和 $[0,1]$。

### 【例3】（综合题）

已知函数 $f(x) = \frac{ax + b}{1 + x^2}$ 是定义在 $(-1,1)$ 上的奇函数，且 $f\left(\frac{1}{2}\right) = \frac{2}{5}$，求 $a, b$ 的值。

??? note "解析"
    奇函数满足 $f(0) = 0$：$f(0) = \frac{b}{1} = 0$，得 $b = 0$。
    
    又 $f\left(\frac{1}{2}\right) = \frac{\frac{a}{2}}{1 + \frac{1}{4}} = \frac{\frac{a}{2}}{\frac{5}{4}} = \frac{2a}{5} = \frac{2}{5}$，得 $a = 1$。
    
    故 $a = 1,\; b = 0$，$f(x) = \frac{x}{1 + x^2}$。

## 常见题型与技巧

| 题型 | 特征 | 解法要点 | 易错点 |
|------|------|----------|--------|
| 求定义域 | 分式、根式、对数等复合 | 列不等式组求解 | 分母 ≠ 0、对数真数 > 0 |
| 求值域 | 给定解析式求范围 | 配方法、换元法、分离常数法 | 定义域对值域的限制 |
| 单调性判断 | 判断/证明函数单调性 | 定义法或导数法 | 用定义时未取 $x_1 < x_2$ |
| 奇偶性判断 | 判断函数奇偶性 | 验证 $f(-x)$ 与 $f(x)$ 关系 | 忽略定义域对称性 |
| 分段函数 | 变量在不同区间表达式不同 | 分类讨论 | 分段点取值判断 |
| 函数图像 | 图像变换、识别 | 平移、伸缩、对称变换 | 变换顺序 |

## 练习

!!! question "练习1"
    求函数 $f(x) = \sqrt{4 - x^2} + \frac{1}{x - 2}$ 的定义域。

    ??? note "答案"
        $\begin{cases} 4 - x^2 \geqslant 0 \\ x - 2 \neq 0 \end{cases} \Rightarrow \begin{cases} -2 \leqslant x \leqslant 2 \\ x \neq 2 \end{cases}$，定义域为 $[-2, 2)$。

!!! question "练习2"
    已知 $f(x)$ 是定义在 $\mathbb{R}$ 上的奇函数，当 $x > 0$ 时 $f(x) = x^2 - 2x$，求 $f(x)$ 的解析式。

    ??? note "答案"
        当 $x < 0$ 时，$-x > 0$，$f(-x) = (-x)^2 - 2(-x) = x^2 + 2x$。
        由奇函数性质 $f(x) = -f(-x) = -x^2 - 2x$。
        又 $f(0) = 0$。
        
        故 $f(x) = \begin{cases} x^2 - 2x, & x > 0 \\ 0, & x = 0 \\ -x^2 - 2x, & x < 0 \end{cases}$。

## 拓展与延伸

!!! tip "拓展"
    - **复合函数**：$f(g(x))$，其定义域由 $g(x)$ 的值域与 $f$ 的定义域共同决定。单调性遵循"同增异减"原则。
    - **反函数**：若 $f$ 是一一映射，存在反函数 $f^{-1}$，满足 $f(f^{-1}(x)) = x$。原函数与反函数的图像关于 $y = x$ 对称。
    - **函数方程**：函数方程（Functional Equation）是竞赛数学常见题型，如柯西方程 $f(x+y) = f(x) + f(y)$。
