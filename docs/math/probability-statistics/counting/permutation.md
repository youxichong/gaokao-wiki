# 排列

**前置知识**：[计数原理](index.md)

!!! note "考纲要求"
    理解排列的概念；掌握排列数公式；能处理有限制条件的排列问题。

## 定义

从 $n$ 个不同元素中取出 $m$ 个元素，按照一定顺序排成一列，叫做从 $n$ 个不同元素中取出 $m$ 个元素的一个排列。

排列数记为 $A_n^m$ 或 $P(n,m)$。

## 排列数公式

$$
A_n^m=n(n-1)(n-2)\cdots(n-m+1)=\frac{n!}{(n-m)!}
$$

特别地：$A_n^n=n!$。

## 常见限制方法

| 类型 | 方法 |
|------|------|
| 特殊元素必须在某位置 | 优先安排特殊元素 |
| 特殊元素不能相邻 | 插空法 |
| 特殊元素必须相邻 | 捆绑法 |
| 顺序固定 | 先排列再除以内部顺序数 |

## 例题

### 【例1】（基础题）

5 名学生排成一排，共有多少种排法？

??? note "解析"
    全排列，共 $5!=120$ 种。

### 【例2】（高质量综合题）

甲、乙、丙、丁、戊 5 人排队，要求甲乙不相邻，共有多少种排法？

??? note "解析"
    先排除甲乙外的 3 人：$3!=6$ 种。
    
    形成 4 个空位：_ A _ B _ C _。
    
    甲乙从 4 个空位中选 2 个并排列：$A_4^2=12$ 种。
    
    总数 $6\times12=72$ 种。

## 练习

!!! question "练习1"
    7 人排队，甲必须在最左端，共有多少种排法？

    ??? note "答案"
        固定甲，其余 6 人全排列，共 $6!=720$ 种。
