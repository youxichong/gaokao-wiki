# 向量概念与线性运算

**前置知识**：无

!!! note "考纲要求"
    理解向量的概念，掌握向量的几何表示；掌握向量的加法、减法、数乘运算及其几何意义；理解向量共线的条件。

## 定义

**向量**：既有大小又有方向的量。记作 $\vec{a}$ 或 $\overrightarrow{AB}$。

**模**：向量的大小，记作 $|\vec{a}|$ 或 $|\overrightarrow{AB}|$。

**零向量**：模为 $0$ 的向量，记作 $\mathbf{0}$，方向任意。

**单位向量**：模为 $1$ 的向量。与 $\vec{a}$ 同向的单位向量记作 $\frac{\vec{a}}{|\vec{a}|}$。

**相等向量**：方向相同、大小相等的向量。

**相反向量**：方向相反、大小相等的向量，记作 $-\vec{a}$。

**共线向量（平行向量）**：方向相同或相反的非零向量。

## 线性运算

- **加法**：平行四边形法则或三角形法则
  - 交换律：$\vec{a} + \vec{b} = \vec{b} + \vec{a}$
  - 结合律：$(\vec{a} + \vec{b}) + \vec{c} = \vec{a} + (\vec{b} + \vec{c})$

- **减法**：$\vec{a} - \vec{b} = \vec{a} + (-\vec{b})$

- **数乘**：$\lambda\vec{a}$，$\lambda \in \mathbb{R}$
  - $|\lambda\vec{a}| = |\lambda| |\vec{a}|$
  - $\lambda > 0$ 时方向相同，$\lambda < 0$ 时方向相反

## 共线定理

$\vec{a} /\!/ \vec{b}$（$\vec{b} \neq \mathbf{0}$）$\iff$ 存在唯一实数 $\lambda$ 使 $\vec{a} = \lambda\vec{b}$。

## 例题

### 【例1】（基础题）

化简 $\overrightarrow{AB} + \overrightarrow{BC} + \overrightarrow{CD}$。

??? note "解析"
    $\overrightarrow{AB} + \overrightarrow{BC} + \overrightarrow{CD} = \overrightarrow{AC} + \overrightarrow{CD} = \overrightarrow{AD}$。
